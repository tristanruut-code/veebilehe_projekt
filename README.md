# Veebilehe-projekt
Tegemist on rühma "KAHAS" veebilehe projektiga.
Projekti eesmärk on lihtsustada õppejõudude kontaktide leidmist, et tudengi vajalikud meilid jõuaksid õige inimeseni.


# Soovitatav töövoog (Kuidas neid kasutada):
Uue ülesande alustamine: Enne koodi kirjutamist luuakse uuest main harust konkreetne funktsiooni haru:git checkout -b feature/css-styling

Commitid ja pushimine: Töötate oma harus, teete regulaarseid ja selgeid commite (nt git commit -m "Lisatud õpetajate kaartide CSS grid"0 ja laadite selle GitHubi: git push origin feature/css-styling).

Pull Request (PR) ja Merge: Kui funktsioon on valmis, teete GitHubis Pull Requesti main harusse. Teised tiimiliikmed saavad koodi üle vaadata ja seejärel vajutate Merge.

Viimane samm: Enne esitamist veenduge, et kõik harud on edukalt main harusse kokku viidud ja kood on seal täiesti korras!
